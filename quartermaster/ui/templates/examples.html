Apartment adviser example

The intended example is a personal apartment valuation adviser: supply apartment details and your policies, then ask for a predicted price and its reasons.

Collect with Muster to capture pages, check extracted details and save policies. In a project's Teach screen, choose a publication and record your preferred prices. The generic prediction/training connection and automatic improvement loop remain planned. This page does not import listings, run a model or create a project.

You can create your own project and add knowledge today. See Help and troubleshooting for the current controls.

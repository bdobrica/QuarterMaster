Help and troubleshooting

Start with knowledge, then teach judgment

Start with your own material; the apartment example describes the workflow. Use Collect for saved pages, links and checked information. Start teaching from the checked collection, then save your personal answers and explanations. Ask about a new situation and optionally Review its answer. Accepted answers and corrections become teaching evidence automatically. Your answer type and unit or choices are saved once per adviser. Knowledge is available within Collect and Teach. Original source bytes are retained; uploaded scripts and formulas are never executed.

Select Markdown as searchable knowledge. Saving creates a new immutable revision; older originals and revisions remain. Upload replacements, select the new source and deselect the old one. Historical training and exports continue to use their frozen versions.

The guided interview has a manual path. Optional builder interpretation, lesson drafting and synthetic example drafting require an exact preview and separate consent before sending business text to the displayed provider. Inspect summaries, excerpts, corrections and advice for sensitive content.

Two ways to learn

Approved knowledge changes affect the next answer immediately. Corrections and accepted judgments are saved for the next improvement; notes and skipped reviews do not create teaching answers. Broader suggested policies remain reviewable before they apply.

Improve my adviser prepares a bounded local training request. Your operator starts it explicitly, and you choose whether to use its resulting version. Saving feedback alone does not change model weights. Small datasets may overfit or fail to improve; personal preferences are not observed outcomes. Cases explicitly reserved for checks remain outside training.

When a request fails

Your saved material and feedback remain available. Check the message, ask your operator if needed, and retry explicitly after fixing the cause.

Advanced · diagnostic codes
BUILDER_CONFIG / BUILDER_AUTH
Ask your operator to check the configured endpoint, model and environment/secret-file credential. Use the manual path meanwhile. Never paste keys into missions or feedback.
BUILDER_INPUT / BUILDER_TIMEOUT / BUILDER_RATE_LIMIT / BUILDER_JSON
Shorten the request or omit excerpts; check the provider's schema support and configured timeout/input limit. Answers remain saved. Prepare a fresh preview and retry explicitly; requests are not retried automatically.
LOCAL_CONFIG / LOCAL_CONNECTION / LOCAL_MODEL / LOCAL_TIMEOUT
The operator must prepare the pinned local model, configure its hash and start the advice profile. Check memory and CPU availability. Retry explicitly; an invalid response is saved as a failed test, not valid advice.
TRAINING_* / EXAMPLE_* / EVALUATION_HELD_OUT
Review every selected target, remove duplicates and choose a frozen unseen suite. Queueing alone does not start training. The operator starts the local worker explicitly after GPU checks. Failed, canceled or interrupted jobs cannot become usable candidates. Never move a holdout into training.
EXPORT_IMAGE / EXPORT_CONTEXT / EXPORT_ARTIFACT / EXPORT_MODEL
Check the exact installed runtime image, candidate lineage and immutable artifact hashes. An export uses evaluated historical context. For different knowledge or lessons, evaluate and train a new candidate. Do not edit archived manifests to bypass a failed check.
EXPORT_DOCKER / EXPORT_CLEANUP / STORAGE_UNAVAILABLE
Ask the operator to check Docker, available disk, permissions and the recorded isolated Compose project. Preserve the archive and sanitized report; stop that test project if cleanup failed. Restore a complete backup with services stopped when storage is damaged.

Give the operator the diagnostic code and record ID. Ordinary logs omit request bodies, keys and uploaded text. Do not enable HTTP debug logging or share the data directory publicly; it contains sensitive original sources, corrections and model artifacts.

Hardware, exports and privacy

Advanced · local model and hardware

The preferred local base is pinned Qwen3.5-4B, about 4.5 GB, tested with four CPU threads and a 6 GiB serving limit. Answers can take a minute. Bounded local training was tested on an 8 GB NVIDIA RTX 2070 SUPER. Conversion allows up to 24 GiB computer memory and needs 32 GB free disk plus image space. The earlier Qwen3.5-0.8B model, about 812 MB with a 4 GiB serving limit, and its historical versions remain supported. Other GPU families and CPU-only training have not been verified. There is no cloud fallback.

An export includes its selected original knowledge bytes, approved lesson text, model and one decision-time reference situation. Review redistribution rights and sensitive content. The package needs its exact runtime image installed first; copying an archive alone does not install Docker or the image. Package creation verifies bytes, not successful startup. Run the separate fresh-container export check before relying on it.

This application has no login and is intended for one trusted local owner. Keep its published ports on localhost. Authentication, HTTPS, upload limits and correct origin handling are operator responsibilities before any reverse-proxy exposure. Do not publish it directly to the internet.

Back up the entire persistent data volume with the web, worker and candidate services stopped; SQLite and artifacts belong together. A standalone adviser export is not a recoverable project backup. The repository's docs/operator-guide.md covers backup/restore commands, GPU setup and license notices.
